One line about a small good thing that happened today: a stranger held the
elevator, then pressed my floor before I could — he had memorized it from
yesterday.

Run `python3 main.py` to write the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` by default). The program gates the text to 1–200
characters, a single line, and verifies the output byte-for-byte.
